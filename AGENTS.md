# Правила работы над приложением

- Работать только в этой папке. Перед изменениями сначала читать текущие файлы.
- Делать только ту функцию, которую просит пользователь. Не ломать уже работающие функции.
- Использовать только обычные HTML, CSS и JavaScript: без npm, фреймворков и внешних ресурсов.
- Данные пользователя остаются в браузере. Ничего не отправлять в интернет.
- Использовать понятные подписи. Высота и ширина полей и кнопок — не меньше 44px. Обеспечить работу с клавиатуры и удобство на телефоне.
- Деньги показывать с пробелами между тысячами, например: 15 000 ₸.
- Пустые и неверные числа считать нулём. Никогда не показывать NaN.
- Не запускать git и ничего не публиковать без просьбы пользователя.
- После работы перечислять изменённые файлы и объяснять, как проверить результат.
